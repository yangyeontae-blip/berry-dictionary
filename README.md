# 베리의 숲 국어사전 🍓

초등 3학년이 **국어사전 찾는 법**을 놀이로 익히는 그림책 사전입니다. 설치 없이 웹에서 열리고, 아이 기록은 그 기기에만 저장됩니다.

## 들어 있는 것 (2022 개정 교육과정 3~4학년 문법)
| 성취기준 | 앱 기능 |
| --- | --- |
| [4국04-02] 단어 분류와 국어사전 활용 | 사전 찾기 놀이(첫 자음 → 모음 → 받침 → 머리 낱말 보고 쪽 넘기기), 기본형 도우미(먹었어요 → 먹다), 이름·움직임·성질을 나타내는 말 표시, 뜻 짐작하고 견주기, 여러 뜻 중 문장에 맞는 뜻 고르기 |
| [4국04-01] 단어 사이 의미 관계 | 비슷한말·반대말 이어 찾기 |
| [4국04-04] 높임 표현 | 높임말·낮춤말 이어 찾기 |

그 밖에: 초성 검색(ㄷㅈㅎㄷ), 오늘의 낱말, 낱말 주머니, 낱말 도장판, 소리 듣기(기기 읽어 주기), 선생님 낱말 목록 링크(서버 저장 없이 주소에 담김).

## 개발
```
npm install
npm run data   # raw/*.xml(한국어기초사전) → public/data
npm run dev
npm test
npm run build
```
자료·글꼴 출처는 [NOTICE.md](NOTICE.md)를 보세요.
